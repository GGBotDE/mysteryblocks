# Code of conduct

Be decent to each other.

Concretely: assume good faith, keep criticism about the code, and skip the
personal remarks. Harassment of any kind is not welcome here, in issues, pull
requests or anywhere else the project happens.

If someone is making the project worse to be part of, open an issue or contact a
maintainer privately. Reports are handled discreetly. Maintainers may edit,
remove or reject contributions that do not fit the above, and may ban repeat
offenders.
